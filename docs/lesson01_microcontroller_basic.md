# 第1回：マイコンのみ

## 目的

ESP32 の基本操作を確認し、LED 出力、ボタン入力、Serial Monitor 出力を扱えるようにします。

## ゴール

- ESP32 にプログラムを書き込める
- LED を点滅させられる
- ボタン入力を読み取れる
- Serial Monitor に値を表示できる

## 使用するもの

- XIAO ESP32C6
- USB ケーブル
- LED
- 抵抗 220Ω 程度
- タクトスイッチ
- ブレッドボード
- ジャンパーワイヤ
