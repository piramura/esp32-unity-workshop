# 部品表

## 必須

| 部品 | 数量 | 用途 |
|---|---:|---|
| ESP32 開発ボード | 2 | 第1回、第2回、第3回で使用 |
| USB ケーブル | 2 | 書き込み、Serial 通信、給電 |
| PC | 1 | ESP32 書き込み、Unity 実行 |
| ブレッドボード | 1 | 回路作成 |
| ジャンパーワイヤ | 適量 | 配線 |
| LED | 1 | Lチカ |
| 抵抗 220Ω 程度 | 1 | LED 電流制限 |
| タクトスイッチ | 1 | ボタン入力 |

## ソフトウェア

| ソフトウェア | 用途 |
|---|---|
| PlatformIO | ESP32 ファームウェアの書き込み |
| Unity | Serial 通信の受信、デモ実行 |
| USB Serial ドライバ | ESP32 が認識されない場合に使用 |

## あると便利

| 部品 | 用途 |
|---|---|
| 追加 LED | 状態表示 |
| 追加ボタン | 入力の拡張 |
| モバイルバッテリー | 送信側 ESP32 の無線デバイス化 |
